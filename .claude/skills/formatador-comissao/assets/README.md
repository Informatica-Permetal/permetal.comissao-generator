# Assets expected from the user

Do not invent corporate branding.

Before Phase 4, the user is expected to provide:

1. Logo files for each company/branch that must appear in report headers.
2. A PDF or image example showing the desired visual direction.
3. When available, legal/company name, CNPJ, address, and branch display text for each branch.
4. Optional application icon.

Observed branch codes in the validated source reports:

- 0103 - PERMETAL SAO PAULO
- 0104 - PERMETAL CRAVINHOS
- 0105 - METALGRADE NOVA
- 0106 - MG

Store supplied logos locally in the application/company profile system. Do not fetch logos from the internet at runtime.

The application itself must remain named `Formatador Comissao`; company branding belongs to generated report documents, not the generic application shell.
